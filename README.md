# test_i2c_PCF8574
# Драйвер MSSP I2C (мастер) для PIC16F1825

Однобайтовый I2C-драйвер для общения с ведомыми без регистров (PCF8574 и
подобные). Построен на автомате состояний, исполняемом по факту события
SSPIF: в отладочной сборке — опрос флага, в production — вектор прерывания.
Устойчив к зависанию ведомого на шине: встроен протокол восстановления
без снятия питания.

## Особенности

- автомат из 7 состояний, каждому состоянию соответствует **ровно один**
  источник SSPIF (даташит MSSP, master mode);
- единая точка завершения `do_EXIT()`: колбэк `exitFunc` вызывается
  **при любом исходе** — штатном, NACK, WCOL, BCL, провале восстановления
  шины;
- расходуемый колбэк: после вызова указатель обнуляется — случайный
  повторный вызов из `_IDLE` невозможен;
- контроль WCOL после обеих записей в `SSP1BUF`, эскалация BCL;
- fail-fast проверка шины перед каждым `I2C_Start` (включая контроль
  физического уровня SDA) и восстановление по протоколу «9 тактов + STOP»;
- poll-режим без правок логики: переход на interrupt — раскомментировать
  две строки (см. wiki).

## Состав

| Файл | Назначение |

> разделение по файлам — к продакшену.

## Быстрый старт

```c
static volatile i2c_api_t i2c_api;

void myExit(void) { done = 1; }        /* флаг: volatile */

void writeByte(void) {
    i2c_api.adr      = 0x40;           /* адрес + R/W (0 = запись) */
    i2c_api.value    = 0xFF;           /* байт данных */
    i2c_api.exitFunc = myExit;
    I2C_Start();
}

int main(void) {
    initChip();                        /* OSC, GPIO, ANSELC, WDT */
    I2C_Init();                        /* MSSP: 100 кГц, SSPEN=0 */
    I2C_Open();                        /* SSPEN=1, state=_IDLE */
    done = 1;
    writeByte();
    while (done) {                     /* ожидание события */
        CLRWDT();
        if (PIR1bits.SSP1IF) I2C_MasterStateEngine();
    }
    /* done = 0 всегда: читайте i2c_api.error */
    I2C_Close();
}
```

## API

| Функция | Когда вызывать | Контракт |
|---|---|---|
| `I2C_Init()` | один раз при старте | регистры MSSP, SSPEN=0; нужны подтяжки на шине |
| `I2C_Open()` | перед серией операций | включает MSSP, `state = _IDLE` |
| `I2C_Start()` | запуск одной операции | поля api заполнены **до** вызова; завершение — по `exitFunc` |
| `I2C_MasterStateEngine()` | при установленном SSPIF | один шаг автомата; флаг очищается на входе |
| `I2C_Close()` | после `exitFunc` | запрещает прерывание и MSSP |

## Дескриптор операции

| Поле | Смысл |
|---|---|
| `adr` | байт адреса с битом R/W (0 — запись, 1 — чтение) |
| `value` | байт данных (запись) или приёмник результата (чтение) |
| `error` | результат: `I2C_OK`, `I2C_ADDR_ERR`, `I2C_DATA_ERR`, `I2C_BUFF_ERR`, `I2C_FATAL_ERR` |
| `exitFunc` | колбэк завершения; вызывается из контекста движка, после вызова обнуляется |

**Правило:** поля дескриптора не изменять от `I2C_Start()` до `exitFunc` —
автоматом они читаются и пишутся на каждом шаге.

## Модель исполнения

`I2C_MasterStateEngine()` вызывается **только** при установленном SSPIF
(вызов без события — ошибка контракта). В poll-сборке — цикл опроса,
в ISR-сборке — тело вектора (PIE1.SSP1IE=1). Все данные, разделяемые
движком и приложением, — `volatile`.

## Ограничения версии 2.1

- один байт данных на операцию; операции с регистром и repeated START
  не поддержаны;
- один api-блок на систему; нет busy-семафора;
- нет таймаута транзакции (WDT — глобальная страховка);
- SMP=0 (slew-контроль активен) — осознанно для 100 кГц.

## Точки роста

- реестр потребителей вместо прямого `exitFunc`;
- multi-byte read (обёртка `I2C_MasterSendAck` уже зарезервирована);
- регистровые операции через repeated START;
- таймаут на базе системного тика.
